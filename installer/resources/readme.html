安装前须知

安装与更新

安装位置为 /Applications/CleanZip.app，系统可能要求输入管理员密码。如果 CleanZip 正在运行，请先结束或取消压缩，再退出应用。安装器会更新此位置的旧版本，不改动你的源文件或已生成的 ZIP。

压缩范围

单个文件和最终 ZIP 需小于 4 GiB。符号链接会跳过，完成后可查看清单。自动清理 .DS_Store、__MACOSX 和 ._* 文件；其余隐藏文件仍会保留。此工具不保留 Mac 资源叉及扩展属性，不适合完整系统备份。

开源构建

采用 MIT 协议。本安装器尚未使用 Apple Developer ID 签名或公证。若系统阻止打开，请确认下载来源，再在「系统设置 → 隐私与安全性」中允许打开。
